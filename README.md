# 家計簿アプリ
React・TypeScript等を使用して制作している家計簿Webアプリケーションです。
現在開発中です。

## 使用技術
- React
- TypeScript
- Java
- PostgreSQL
- Git / GitHub

## 主な機能
- 家計簿の登録・編集・削除
- 収入・支出の管理
- カテゴリ別の管理
- 家計簿データの一覧表示

## 開発内容
- 画面デザイン設計
- 画面遷移図作成
- 設計書作成
- DB設計
- DBのCREATE文作成
- フロントエンド開発
- バックエンド開発

## 開発状況

現在も機能追加・修正を行いながら開発を進めています。
